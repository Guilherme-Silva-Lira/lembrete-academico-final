Lembrete Acadêmico Dashboard

Projeto acadêmico

Sistema de Lembrete Acadêmico

Uma aplicação para organizar atividades, acompanhar prazos e tornar a rotina de estudos mais previsível.

Objetivo

Centralizar tarefas acadêmicas com prioridade, prazo, progresso, filtros, materiais de apoio e alertas de vencimento.

Tecnologias

HTML5 CSS3 JavaScript Bootstrap 5 LocalStorage
